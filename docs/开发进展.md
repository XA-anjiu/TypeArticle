# TypeArticle · 开发进展与项目说明

> 平板「文章跟打 + 单词默写」App。纯本地、离线优先。
> 目标设备：华为 MatePad Pro 10.8（2021，MRR-W29，HarmonyOS 2/3，无 GMS）+ 蓝牙实体键盘。
> 本文件为长期开发日志：每天优先推进时，先在末尾「更新日志」追加当日内容。

### 1.2 内容质量

- **修复小数被拆句**：如 `16. 7%`、`88.`↵`24%`、`a.`↵`m.` → 正确还原为 `16.7%`、`88.24%`、`a.m.`（脚本修正 10 篇）。
- **句级重切**：15 篇 Part B 首段存在「一行含多句」，全部按真句切开（脚本 8 篇 + 手动对齐 8 篇），保证每句为一个跟打单位。
- **逐句中文译文**：为全部 32 篇添加 `textTranslate`，与英文**段/句严格 1:1 对齐**（283 句；脚本校验 `FINAL ALIGNMENT OK: True`）。

### 1.3 前端界面（按确认的「沉浸极简」方案）

- 侧栏：品牌 + **文章列表**（真实 32 篇，点击切换）+ **单词默写入口** + **默写模式开关** + **设置入口** + **夜间/浅色切换** + **收起/贴边按钮**（收起后左侧出现 `›` 贴边 tab）。
- 主区：顶栏（标题 + 进度条 + 篇号/百分比/用时/错误 + `译文开关` / `←` / `R` / `→`）；**句进度点**；居中大字正文；**当前句深色、其余句淡色**；当前词高亮框 + 光标闪动 + 打错红底；默写模式整句/整词变下划线。
- **自动居中**：当前正在打的那一句会自动滚动到屏幕垂直中部（首句贴顶属正常）。
- 设置页：**书库 / 词库 分段切换** + 导入 + **删除**；**快捷键卡**；**音效卡**（见 1.4）。
- 结算页：用时 / 词数 / 错误 + 重练本篇 / 下一篇。
- 主题：浅色（`#F2F2F7`）/ 深色（纯黑 `#000000`），色板与 EUI-NEO `theme.h` 对齐（主色 `#3871E0`，圆角 18/16/22/6）。

### 1.4 打字音效（移植自 TypeWords）

- 音效文件拷入 `app/src/main/res/raw/`：`beep.wav`、`correct.wav`、`key_m0..3.mp3`、`key_jixie1/2.mp3`、`key_old.mp3`、`key_laptop.mp3`。
- `AndroidAudioService` 用 `SoundPool` 预载（单文件选项预载 4 份，支持连打不吞音），失败降级 `ToneGenerator`。
- 设置页「音效」卡：**按键音**、**出错提示音** 开关；**键盘音效切换**：`机械键盘 / 机械键盘1 / 机械键盘2 / 老式机械键盘 / 笔记本键盘 / 关闭`。

### 1.5 输入链路加固（无键盘也能验证）

- 由 `onKeyDown` 改为 **`dispatchKeyEvent`**，优先于界面消费按键，避免聚焦按钮抢走空格/方向键。
- 只白名单处理：可打印字符、空格、退格、左右方向键；**返回键/音量键/上下键放行**给系统。
- 已用 `adb shell input text/keyevent` 模拟验证：`Dear`+`空格`+`Joe` 能正确高亮、推进、计时、计错。

### 1.6 性能优化

- `PracticeViewModel.renderState`：**光标未变（如每秒 tick）时只更新统计、不重建整篇 sections**。
- 段落渲染：**非当前句整句一次渲染**（只用基本类型参数，可跳过重组），当前句才逐词渲染 → 大幅减少 composable 数量。
- 模型加 `@Immutable`，利于 Compose 跳过重组。

### 1.7 视觉修正

- 未打=淡色、**当前句=深色**（此前理解反了，已纠正）。
- 词级高亮框、打错红底、光标闪动。
- **修正行距过小导致的行重叠**（正文 `lineHeight=52sp`）。
- 收起侧栏时**左右留白加倍**（更居中，不贴边）。

## 2. 项目结构

```
typearticle/
├─ app/
│  ├─ build.gradle.kts
│  └─ src/
│     ├─ main/
│     │  ├─ AndroidManifest.xml            # 仅 INTERNET 权限；resizeableActivity
│     │  ├─ assets/articles_2010_2025.json # 内置文章包（32 篇，含逐句译文）
│     │  ├─ res/raw/                       # 打字音效（移植自 TypeWords）
│     │  └─ java/
│     │     ├─ com/example/
│     │     │  ├─ MainActivity.kt          # 承载 UI + 硬件键 dispatchKeyEvent + 生命周期计时

│     │     │     ├─ AppUi.kt              # 组件：卡片/胶囊/按钮/键帽/开关/分段/统计盒
│     │     │     ├─ AppRoot.kt            # 侧栏 + 路由 + 模式 + 收起贴边
│     │     │     ├─ PracticeContent.kt    # 文章跟打 + 单词默写 + 结算 + 自动居中
│     │     │     └─ SettingsContent.kt    # 书库/词库 + 快捷键 + 音效
│     │     └─ com/example/typingarticle/
│     │        ├─ core/
│     │        │  ├─ model/        # Book/Article/Sentence/Token/Cursor/Stats/Settings/EngineSnapshot
│     │        │  ├─ parser/       # ArticleParser（引号归一/切段切句/词元化/nextSpace）
│     │        │  ├─ engine/       # TypingEngine（状态机）+ KeyMapper
│     │        │  ├─ data/         # Room(Entity/Dao/Database) + Repository + builtin
│     │        │  ├─ audio/        # AudioService（TTS/ExoPlayer/SoundPool/ToneGenerator）
│     │        │  └─ settings/     # SettingsRepository（DataStore）
│     │        ├─ feature/
│     │        │  ├─ practice/     # PracticeViewModel + PracticeUiState（UI 契约）
│     │        │  ├─ word/         # WordDictationViewModel + WordUiState
│     │        │  └─ settings/     # SettingsViewModel（书库/词库/设置）
│     │        ├─ di/              # TypingDiContainer
│     │        └─ app/             # TypingApplication
│     └─ test/                     # JVM 单测（解析/引擎/单词/进度统计）
├─ gradle/libs.versions.toml
├─ gradlew / gradlew.bat / gradle/wrapper/
├─ build.gradle.kts / settings.gradle.kts / gradle.properties
└─ README.md / docs/开发进展.md（本文件）
```

### 分层约定

- `core/parser`、`core/engine`：**纯 Kotlin，禁止依赖 `android.*`**，可在 JVM 单测。
- `feature/*ViewModel`：**UI 无关注入**（不依赖 Compose），对外只暴露 `StateFlow<UiState>` + 公开命令。
- `ui/*`：仅消费 UiState 与调用 ViewModel 方法，不改内核。

## 3. 构建与运行

```powershell
# 在项目根目录
.\gradlew.bat :app:assembleDebug          # 编译 debug APK
.\gradlew.bat test                        # 运行 JVM 单测

# 安装到已连接设备（需开启 USB 调试并授权）
adb install -r -t -g app\build\outputs\apk\debug\app-debug.apk
adb shell am start -n com.aistudio.typingarticle.hwmpkb/com.example.MainActivity
```

- 工具链：JDK 17、Gradle 9.3.1、AGP 9.1.1、Kotlin 2.2.10、KSP 2.3.12。
- Android：`compileSdk 36 / targetSdk 34 / minSdk 26`。
- 签名：debug 用 AGP 默认签名；release 需要 `KEYSTORE_PATH / STORE_PASSWORD / KEY_ALIAS / KEY_PASSWORD`（或放 `my-upload-key.jks`），否则产出未签名包。

> 华为设备 `adb` 提示 `offline` 多为**锁屏**或需重新授权：解锁屏幕 → USB 模式「传输文件」→ 若仍 offline，开发者选项「撤销 USB 调试授权」后重插并点「始终允许」。

## 4. 内容包与词库

- **文章包**：`app/src/main/assets/articles_2010_2025.json`（`Article[]`，字段 `title / titleTranslate / text / textTranslate / audioSrc? / lrcPosition? / nameList?`）。
  - `text`：段落用空行分隔（`\n\n`），**段内一句一行**（`\n`）；`textTranslate` 与之一一对应。
  - 替换：直接改该 assets 文件，**清空应用数据**后重启即重新导入（书籍 id：`book_english_writing_2010_2025`）。
- **词库**：设置页可导入 `.txt`（一行一词）/ `.json`（`string[]` 或 `{word, phonetic0, phonetic1, trans}[]`）/ 逗号制表格；内置示例词 30 个。

## 5. 快捷键

| 功能 | 按键 |
|---|---|
| 开启 / 关闭译文 | `Ctrl + T` |
| 收起 / 展开侧栏 | `Ctrl + B` |
| 默写 / 跟打 切换 | `Ctrl + D` |
| 深色 / 浅色 切换 | `Ctrl + J` |
| 下一句 / 上一句 | `→` / `←` |
| 重播当前句 | `R` |
| 单词 / 空格确认 | `Space` |
| 回删 | `Backspace` |

> 判定规则：逐字符比对（忽略大小写可选）；词尾需空格时进入「等待空格」态，仅空格可推进（按其它键会推进并重放该字符，不吞键）；标点/数字默认需输入（可在设置关闭「过滤符号」等）。
